One line of at most 160 characters: a deadpan one-star review of an everyday essential. The program writes the line to /output/entry.txt; the bounty judge compares entries two at a time and keeps the funnier one. The essential under review is oxygen: free, unlimited, and filed against in earnest for the one defect nobody can return it for, that it runs out one flight of stairs sooner than it used to. The complaint is read straight, the deadpan never breaks, and the sting is saved for the last few words.

## Run it

```sh
python3 main.py
```
